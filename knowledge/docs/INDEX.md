# 手写文档索引

skill 和 GitHub 是脚本同步的。**以后要加的说明书、纪要、备忘，放这里。**

丢文件：`knowledge/docs/<主题>/<名字>.md`  
还没想好分类：先放 `knowledge/docs/inbox/`，用的时候再挪。

加完后在下表补一行，Agent 才找得到。不要全目录扫。

| 文档 | 路径 | 一句话 |
|---|---|---|
| _- | docs/inbox/_-.md | 用户导入 |

## Agent 怎么读

1. 先看本表，对上主题再 `read` 那一个文件。
2. 表里没有、用户又明确说了某份文档，再在 `docs/` 下按文件名搜。
3. 流程类问题仍先走 `../skills/INDEX.md`，项目类先走 `../github/INDEX.md`。这里只收「不属于 skill、也不属于仓库元数据」的材料。
